## Trust Boundaries

|---|---|
| Local executable/process output → doctor result | Host command output is untrusted and must be bounded/redacted. |

| T-BAOPS-01-08-NET | Information Disclosure | Doctor probes | high | mitigate | No package/update queries; run the complete matrix under socket/DNS denial. |
| T-BAOPS-01-08-MUT | Tampering | Read-only diagnostics | high | mitigate | Expose no writer/cleanup operations and snapshot bytes/mtimes around all runs. |
