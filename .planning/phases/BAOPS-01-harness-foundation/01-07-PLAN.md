## Trust Boundaries

| Boundary | Description |
|---|---|
| Human/automation → network-capable installer | Consent, offline source, host executable, and arguments enter the only network-capable surface. |
| Package artifacts → project-local generation | Approved executable bytes become an isolated environment. |
| Active pointer → launcher | Local text selects the interpreter to execute. |

## STRIDE Threat Register

| T-BAOPS-01-07-DEPS | Tampering / Elevation of Privilege | Dependency installation | high | mitigate | Exact approved hash lock, binary-only, no extra index, local package no-deps/no-build-isolation, and argv tests. |
| T-BAOPS-01-07-PTR | Tampering / Elevation of Privilege | Pointer and launchers | high | mitigate | Strict component allowlist, contained interpreter construction, exact-version verification, atomic activation, and malicious-pointer tests. |

| T-BAOPS-01-07-CONSENT | Repudiation | Online dependency access | medium | mitigate | Exact default-No prompt, explicit per-invocation `--yes`, offline mode, no persisted consent, and captured evidence. |
